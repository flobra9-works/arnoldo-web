# Shot list — Gelateria Arnoldo

Platzhalter-JPEGs liegen hier, bis die Auftraggeberin Fotos liefert.

Minimum (Spec §3 / §7):

1. Hero — editoriales Gelato oder Salon-Still, warmer Grade, Querformat, 2400px+
2. Signatur-Sorten (5): Amarena, Bacio, Sicilia, Haselnuss, Pistazie — in der Schale, gleiches Licht
3. Übriges Sorten-Raster kann einen geschmackvollen Fallback teilen, bis Einzelbilder da sind
4. Handwerk / Hände / Zutaten
5. Salon-Innenraum
6. Gastgarten
7. Detail (Glas, Holz, Theke)
8. Optional Familienporträt (Fausto & Sonja)
9. Wortmarke SVG (ersetzt den Text-Schriftzug im Header)

Vor dem Feinschliff außerdem: Öffnungszeiten / Feiertagsausnahmen bestätigen; Impressum (FN, UID, Gericht) bestätigen.
